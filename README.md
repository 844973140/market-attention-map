# 市场注意力地图

一个纯中文的金融市场注意力可视化原型，通过公开市场数据和明确标注的模拟数据，观察全球资本当前关注正在集中于哪些市场。

项目采用 Next.js、TypeScript 与 ECharts，可直接部署到 Vercel。页面不提供价格预测、资金流判断或买卖建议。

## 数据来源

- **CoinGecko**：比特币、以太坊的价格变化、成交量和市值。没有密钥时尝试公开接口，失败后自动使用模拟数据。
- **GDELT**：比特币、以太坊、人工智能、科技股、黄金与原油相关新闻关注度。
- **模拟数据**：股票市场和大宗商品的市场指标。页面会显著显示“模拟数据”，不会伪装成实时行情。

所有外部请求都在服务端完成并设有超时。任一 API 不可用时，页面仍会展示完整 Demo。

## 市场关注度指数

市场关注度指数范围为 0–100，按以下权重计算：

1. 成交量变化：50%
2. 价格变化：30%
3. 新闻热度：20%

计算前分别对三个分量进行 0–100 归一化，再计算加权分数，最后对加权结果归一化。价格变化使用绝对幅度表示“被关注程度”，涨跌方向独立显示，不把上涨等同于更受关注。

核心公式位于 `src/lib/attention.ts`，与外部数据采集代码分离。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。

构建检查：

```bash
npm run typecheck
npm run build
```

## Vercel 部署

1. 在 Vercel 导入本 GitHub 仓库。
2. Framework Preset 选择 Next.js，其他设置保持默认。
3. 如有 CoinGecko 演示版密钥，在 Vercel 项目环境变量中添加 `COINGECKO_API_KEY`；不要提交到仓库。
4. 点击部署。后续推送会自动触发新部署。

也可使用命令行：

```bash
npx vercel
npx vercel --prod
```
